# خارطة الطريق (Roadmap) - مشروع Aegis

## الهدف

توضح هذه الوثيقة مراحل تطوير مشروع Aegis من النسخة الأولى إلى الإصدارات المستقبلية.

---

# المرحلة الأولى (MVP)

## البنية الأساسية

- إعداد المستودع (GitHub)
- إعداد قاعدة البيانات
- إنشاء REST API
- نظام تسجيل المستخدمين
- تسجيل الدخول
- إدارة المحافظ

---

## المعاملات

- تحويل الأموال
- سجل المعاملات
- التحقق من الرصيد

---

## الأمان

- JWT
- تشفير كلمات المرور
- HTTPS
- سجل العمليات
